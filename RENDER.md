# Запуск Nekota Streams на Render

Бот и сервер работают вместе в одном платном Web Service. Render автоматически выдаёт HTTPS-адрес и передаёт его программе через RENDER_EXTERNAL_URL. Отдельный домен не обязателен.

## Подготовка

1. Создайте приватный репозиторий GitHub и загрузите в него app.py, requirements.txt, render.yaml и .gitignore. Не загружайте токен, базу или файл .env.
2. В Render подключите репозиторий и создайте Blueprint по render.yaml. Проверьте выставленные сервис, платный план и диск 1 ГБ до подтверждения платных расходов.
3. В настройках окружения Render укажите BOT_TOKEN (выданный BotFather) и ADMIN_ID (ваш числовой Telegram ID). ADMIN_ID задаёт первого администратора при создании базы. Не присылайте токен в переписку.
4. Проверьте, что диск подключён по пути /var/data и DB_PATH равен /var/data/data.sqlite3. Запустите развёртывание. Публичный адрес указывать вручную не нужно: Render задаёт RENDER_EXTERNAL_URL.
5. Откройте бота, нажмите Start и отправьте /setlink с действительным HTTPS-адресом стрима. Проверьте переход, уведомление и /getlogs.
6. Перезапустите сервис, ещё раз запросите /getlogs и проверьте сохранение. Затем передайте права другу по инструкции в README.md.

## Контроль IP

При публичном входе на Render приложение использует CF-Connecting-IP, предоставляемый входной инфраструктурой Render. Проверить реальный IP и устойчивость к поддельным заголовкам нужно после развёртывания; локальная проверка не доказывает поведение сетевой инфраструктуры Render. Режим Render не предназначен для прямого доступа к приложению или другого прокси. Не включайте частный сетевой доступ посторонним сервисам. При отсутствии корректного заголовка бот записывает «неизвестен».

Используется один экземпляр: несколько ботов с одинаковым токеном одновременно запускать нельзя. При обновлении сервиса с диском возможна краткая недоступность. Бесплатный сервис без постоянного диска не сохраняет базу при перезапуске и засыпает.

У администратора Render и владельца токена есть технический доступ к управлению приложением. Передача прав внутри бота не заменяет передачу аккаунтов и перевыпуск токена. Персональные ссылки можно переслать; предпросмотры могут вызывать переходы. Уведомление аудитории о сборе IP предоставляется отдельно организатором.
